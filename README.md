# 🖤 NOCTURNE STUDIO — Modern Apparel & Streetwear Design System

*"Elegance Built in the Shadows"*

NOCTURNE STUDIO is a modern, high-fashion clothing brand blending minimalist aesthetics with high-grade streetwear. Designed for everyday luxury, versatile layering, and effortless style.

---

## 🎨 Brand Aesthetic & Color Palette

| Color Name | Hex Code | Purpose & Usage |
| :--- | :--- | :--- |
| **Matte Obsidian** | `#0F0F0F` | Primary garment shade & website dark background |
| **Cool Charcoal** | `#262626` | Secondary fabrics, denim washes & UI cards |
| **Monochrome White** | `#FAFAFA` | High-contrast typography & minimalist logo print |
| **Raw Cream** | `#E5E0D8` | Natural cotton tones & hangtag accents |

---

## 🧥 Signature Apparel Collection

1. **Nocturne Oversized Heavyweight Hoodie**
   * *Fabric:* 450 GSM Organic Terry Cotton.
   * *Fit:* Drop-shoulder relaxed boxy fit with tonal silver embroidery.

2. **Shadow-Tee Essential Drops**
   * *Fabric:* 240 GSM Combed Cotton.
   * *Design:* High-density minimalist chest print with reinforced ribbed collar.

3. **Obsidian Cargo Trousers**
   * *Fabric:* Water-resistant matte ripstop fabric.
   * *Features:* Tactical utility pockets with magnetic closures.
